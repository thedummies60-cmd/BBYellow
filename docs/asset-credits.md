# Asset credits and licenses

Every third-party asset in this repository is listed here. An asset without an entry is
not cleared to ship — the build is public and redistributed, so provenance is not
optional.

Add the entry in the same commit that adds the asset.

## Rules

- Record the license by name (CC0, CC-BY-4.0, purchased, commissioned, original).
- CC-BY and similar require attribution **in the shipped build**, not just here — the
  in-game credits screen reads from this table.
- "Found online" is not a provenance. Untraceable assets get removed.
- Placeholder assets are tracked here too, marked `PLACEHOLDER`, and must be cleared or
  replaced before release.
